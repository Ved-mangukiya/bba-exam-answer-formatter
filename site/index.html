📖 What is this?

The BBA Answer Formatter is a static web app that transforms raw JSON exam-answer data (generated by AI tools like NotebookLM or Gemini) into print-ready, A4-formatted GTU/SSASIT answer sheets. Every page strictly follows the official formatting rulebook — typography, margins, headings, and layout.

⚙️ How does it work?

1
JSON Data In Exam Q&A data is stored in structured JSON files (or imported via the upload button). Each file follows the question-answer.schema.json format.
2
GTU Renderer The renderer.js engine reads the JSON and converts each question/answer block into semantic HTML — headings, paragraphs, bullet lists, tables, and diagrams — following RULES.md formatting rules.
3
A4 Preview on Screen The rendered HTML is placed inside a simulated 210mm × 297mm A4 canvas with real print margins (GTU standard: 20mm top/bottom, 20mm left binding, 15mm right). You can zoom, fit-to-width, and browse individual questions.
4
PDF Export Each A4 sheet is captured pixel-perfectly by html2canvas and assembled into a multi-page PDF by jsPDF. Every page maps 1:1 to an A4 sheet — no text slicing across page boundaries.
5
Direct Download The compiled PDF blob is saved to your device using the File System Access API (Desktop) or a standard anchor download — no print dialog, no browser chrome, just the PDF.

🛠️ Tech Stack

HTML5 Vanilla CSS Vanilla JS html2canvas 1.4 jsPDF 2.5 Node.js scripts 100% Static No backend
